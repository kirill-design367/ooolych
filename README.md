# ООО «Луч»

Сайт оптового каталога на PHP 8.1+ для REG.RU. Витрина, редактор каталога, заявки с вложениями и логотип. Складские иллюстрации показывают группы продукции. Начальный ассортимент взят из списка компании. Цены редактор заполняет сам.

## Запуск

Нужны PHP с PDO SQLite, mbstring и ZipArchive. Каталог и заявки хранятся на сервере. Корень домена должен указывать **только на public/**. Директории app/, bin/ и var/ располагаются вне публичного корня. При размещении public/ под другим именем (например, www/имя-домена) сохраните относительное расположение app и публичного корня или используйте символическую ссылку на public.

1. Разместите исходники на хостинге. Выделите каталог для данных с правом записи для PHP. По умолчанию используется var/ в корне проекта. Через LUCH_DATA_DIR можно задать другой **абсолютный** путь вне публичного корня. При последующих выкладках сохраняйте этот каталог и резервируйте его вместе с вложениями.
2. Запустите из каталога проекта `php bin/admin-password.php` под пользователем сайта и задайте пароль редактора. Скрипт читает пароль из stdin. Вместо файла admin.hash допускается переменная LUCH_ADMIN_HASH с хешем PHP password_hash.
3. Для локальной проверки запустите `php -S 127.0.0.1:8080 -t public`. На хостинге включите HTTPS для домена, установите upload_max_filesize ≥ 8M и post_max_size ≥ 10M. Панель доступна по /admin/.
4. Все заявки сохраняются в разделе «Заявки». Для дополнительных писем в отдел продаж настройте почтовый транспорт PHP и установите LUCH_MAIL_ENABLED=1 для веб-процесса. Адрес получателя задан в app/core.php. Проверьте доставку тестовой заявки после подключения домена. Если почтовый транспорт недоступен, обращение остаётся в панели.
5. Перед подключением рабочего домена подтвердите контакты, текст обработки данных, параметры поставки и ассортимент. Сделайте проверочную заявку, откройте её в панели и скачайте вложение.

## Каталог

В /admin/ редактируются категории, подкатегории, товары, фотографии, характеристики, единицы заказа и цены. Сохранение меняет черновик. Кнопка «Опубликовать каталог» обновляет публичные страницы. Одновременные правки защищены проверкой версии. Позиции, снятые с публикации, сохраняются в ранее отправленных заявках.

Файлы знака и логотипа находятся в public/assets/mark.svg и public/assets/logo.svg. Шрифт Inter распространяется на условиях SIL OFL, текст лицензии включён.
