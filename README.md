# ООО «Луч»

Витрина оптовых поставок по Москве и области. Главная, каталог с фильтрами, калькулятор, список материалов и форма заявки. На странице `/fonts/` можно сравнить три пары шрифтов.

## Локальная разработка

Нужны Node.js 24 и npm. В каталоге `web` выполните `npm ci` и `npm run dev`. Этот режим использует демонстрационный ассортимент и позволяет скачать заявку. Данные для статического сайта и ориентиры цен редактируются в `web/lib/catalog.ts`.

## Полный сайт с заявками и редактором

1. Из `web` выполните `npm ci` и `npm run build:php`. Команда соберёт витрину и разместит её в `public/` рядом с PHP API. Пересобирайте после изменений интерфейса.
2. Нужны PHP 8.1+, PDO SQLite, mbstring и ZipArchive. Корень домена должен указывать на `public/`. Данные и вложения находятся в закрытом каталоге `var/`. Через `LUCH_DATA_DIR` можно указать другой абсолютный путь. Сохраняйте этот каталог при выкладке.
3. Из корня проекта задайте пароль редактора командой `php bin/admin-password.php`. В облачной среде можно использовать `.local/php/bin/php`. Локальный запуск — `php -d upload_max_filesize=8M -d post_max_size=10M -S 127.0.0.1:3000 -t public`. На хостинге настройте HTTPS.
4. Панель доступна по `/admin/`. Изменения каталога публикуются из черновика. Авторизованный редактор видит заявки и скачивает вложения. Для дополнительных уведомлений настройте почтовый транспорт и `LUCH_MAIL_ENABLED=1`.

## GitHub Pages

Workflow в `.github/workflows/pages.yml` собирает статическую версию с базовым путём `/ooolych` и загружает `web/out`. В настройках Pages источником публикации должен быть GitHub Actions. Статика показывает цены из исходника и готовит файл заявки для отправки по почте. Серверные функции доступны на PHP-хостинге.
