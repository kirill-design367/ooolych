# Приёмка витрины ООО «Луч»

Проверена локально собранная версия для GitHub Pages с базовым путём `/ooolych` и HTTP-сжатием. Lighthouse запускался в Chromium. Числа относятся к этому прогону.

| Главная | Компьютер | 99 | 100 |
| Каталог | Телефон | 93 | 100 |
| Каталог | Компьютер | 100 | 100 |

## Сценарии

Проверены фильтр категории и обратный переход, изменение количества и расстояния в калькуляторе, добавление второй позиции, передача PDF через форму и запись в SQLite. Содержимое вложения после сохранения совпало с исходным. В статической версии проверено скачивание файла заявки. На ширине 2560 пикселей дополнительно проверено отсутствие горизонтального переполнения.

На ширине 390 и 1440 пикселей проверено изменение размеров стеклянного меню при скролле, движение строки и машины, а также их остановка при включении уменьшенного движения.

[Галерея семи знаков](logo-gallery.jpg) доступна на сайте по пути `/logo/`. Проверены скачивание семи самостоятельных SVG, кнопка каталога и плавное изменение ширины меню на экранах 320, 390, 1024 и 1440 пикселей.
